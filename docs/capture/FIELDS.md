# 字段覆盖

格式版本 `schemaVersion = 1`。渲染记录版本 `klecks-checkpoint-png-1`。代码版本 `53e046b`。

| 字段组 | 状态 | 记录方式 | 与画布的关系 |
| --- | --- | --- | --- |
| 匿名作者、作品编号、标题、自由/指定、主题、参考、来源、授权 | 已支持 | 开始会话时写入 `session` | 不改变画布 |
| 会话编号、开始时间、续画来源、开始/暂停/恢复/结束 | 已支持 | `session` 与 `interval` | 暂停冻结画板；暂停中的其他编辑另记 |
| 画布尺寸、图层元数据、终图/过程检查点 | 部分支持 | 尺寸和图层属性每次历史提交都记；PNG 检查点在笔画结束后异步生成 | 检查点是操作后的图层合成，保留 Alpha |
| 原始笔输入 | 已支持 | `pre_stabilizer`：画布坐标、performance 时间、pressureRaw、笔刷使用的压力、指针类型、合并采样、中断原因 | 坐标已从视口变换到画布；不是稳定后的点 |
| 稳定后绘制输入 | 已支持 | `post_stabilizer`：笔刷实际收到的 down/move/up/line | 与原始点分开存放 |
| 笔刷配置 | 部分支持 | 笔画开始时保存工具、颜色、尺寸、透明度、稳定器档位、目标图层，以及笔刷对象上的简单字段 | 随机数状态无法读取，字段为 null |
| 编辑历史 | 部分支持 | Klecks 历史提交记为 push/undo/redo，保留分支来源，不删除旧操作。瓦片像素不复制进日志 | 可靠画面以 PNG 检查点为准；瓦片级重放未实现 |
| 撤销/重做 | 已支持 | 新操作指向当时的活动序号；撤销后的新笔画带 `branchParentSequence` | 不从 Klecks 历史里抹掉被撤销的步骤 |
| 视口 | 部分支持 | 缩放、平移、旋转、镜像在变化停顿约 120ms 后记一条 | 不是连续轨迹，也不写入画布内容 |
| 时间 | 已支持 | 实际时间、过程时钟、操作顺序分开。明确暂停不计。页面隐藏只记不确定性 | 过程时钟不是净落笔时长，也不是回放长度 |
| 质量与版本 | 已支持 | 保存失败、检查点缺口、可见性、配置、浏览器环境 | 驱动和数位板仅表单填写 |
| 重要性/事件监督 | 缺失 | 按研究方案留待算法设计 | 不在本次记录里自定协议 |
| 远程提交验收 | 缺失 | 只有本地提交号和 ZIP | 未连接服务时不得视为已验收 |
| 24fps 原长视频 | 缺失 | Demo 基线中的未完成项，本次未做 | 无 |

不能由笔刷参数可靠重放的效果（涂抹、滤镜、变形、填充、随机器）依赖操作后的 PNG。排队超过 2 个检查点时，中间画面可能没有独立 PNG，操作日志仍保留。
