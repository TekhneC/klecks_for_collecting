# Klecks 过程采集使用说明

基线是 Klecks `53e046b`（0.11.3.3）。采集层尚未提交。旁边的 iDrawProcess 仓库有自己的治理记录；本目录的字段对照仍写明依据研究方案第 6.3 节，不把那个仓库当作格式来源。6.3 原文不在本仓库，这里未核对。

2026-10-21：下文的按钮名称，以及「续画不会自动替换当前画布」，与当前界面和代码不一致。冲突记在 [E0001](../../governance/explorations/E0001-canvas-restore.md)，两边都还不是已接受做法。按下文试采前先看该记录。

## 启动

```powershell
cd C:\Users\tekhnec\Projects\klecks
npm run icon:build
npm run lang:build
npm run start
```

浏览器打开 http://localhost:1234/ 。左下角有「过程采集」面板。

本机 Node.js 24.21.0 在 `%LOCALAPPDATA%\node-v24.21.0-win-x64`。新终端若找不到 `npm`，把该目录加入 PATH。

## 试采步骤

1. 填写匿名作者编号。作品编号可留空，开始时自动生成。
2. 填写标题、自由或指定、主题、参考材料、来源和授权范围。数位板和驱动不知道就留空。
3. 点「开始」。用 Klecks 正常绘画。过程时钟包含落笔间隙和思考，只在点「暂停」后停止。
4. 暂停会冻结画板指针。图层、滤镜等若仍改动画布，会记为暂停期间编辑，并在面板计数。
5. 点「恢复」继续同一会话。点「结束」停止过程时钟。
6. 关闭页面前点「保存」。重新打开后，Klecks 自己的恢复功能负责画布；采集面板点「续画」会新开一个会话并接上过程时钟。续画不会自动替换当前画布，请先用 Klecks 恢复同一幅画。
7. 「导出」下载 ZIP，内有 `record.json` 和 PNG 检查点。透明通道保留，不铺背景色。
8. 「本地提交」生成同一提交号的 ZIP。再次点击不会另建提交号。没有远程服务，页面不会显示远程验收。
9. 「回放」或重新选择 ZIP，只读查看记录和检查点，不改采集历史。

配置示例见项目根目录 `capture-config.example.json`。页面使用同内容的内置默认值。
