# Klecks 过程采集使用说明

基线是 Klecks `53e046b`（0.11.3.3）。采集层已在本地提交（`0c42feb` 起）。旁边的 iDrawProcess 仓库有自己的治理记录；本目录的字段对照仍写明依据研究方案第 6.3 节，不把那个仓库当作格式来源。6.3 原文不在本仓库，这里未核对。

已实现的相关决定见 [D0001](../../governance/decisions/D0001-session-lifecycle-and-canvas-restore.md)：
- 画布只经采集检查点恢复，Klecks 自带恢复不保留；非绘画进程中打开或续画已有作品一律用目标作品最晚的采集检查点替换画布。
- 绘画进程中切换、打开已有作品或转到另一幅作品继续绘画前，先提示保存当前绘画；保存完成后再用目标作品最晚的采集检查点替换画布。
- 点击「结束」保存并落盘末位检查点后，过程时钟复位为 `idle` 并回到首页；绘画中进入「作品信息」页时自动暂停计时，点「返回绘画」回到画布后自动恢复计时（原本手动暂停的保持暂停）。

管理页说明（2026-10-29）：管理收集不从绘画页进入，地址是 http://localhost:1234/?admin 。第一次在该页设置管理密码；进入后在同一页修改密码，不另开重置页。密码只保存在这台浏览器。管理页选中作品后，回放嵌在该作品的收集信息页里。删除作品在这一页右上角，也可以删除作者。这里不是远程验收。

## 启动

```powershell
cd C:\Users\tekhnec\Projects\klecks
npm run icon:build
npm run lang:build
npm run start
```

浏览器打开 http://localhost:1234/ ，页面先显示全屏「进入采集」入口页；进入绘画后，底部显示采集停靠栏。

本机 Node.js 24.21.0 在 `%LOCALAPPDATA%\node-v24.21.0-win-x64`。新终端若找不到 `npm`，把该目录加入 PATH。

## 试采步骤

1. 在入口页填写匿名作者编号。编号有内容后出现「新建作品」和「选择已有作品」。作品编号在新建进入时自动生成。
2. 新建作品时，创作类型默认自由，标题和其他信息可以留空；选择已有作品时，列表在标题旁显示最后更新时间。选定后点「进入绘画」。
3. 选择已有作品打开或续画时，画布一律替换为该作品最晚的采集检查点（Klecks 自带恢复已关闭，避免混淆）。续画会新开一轮会话，接上原作品的过程时长与操作序号。
4. 用 Klecks 正常绘画。过程时钟包含落笔间隙和思考，只在明确暂停、观看回放或填写作品信息时停止；切后台不会暂停。
5. 点底部栏「暂停休息」冻结画板指针与计时，再点「继续绘画」恢复同一轮会话。暂停期间若通过图层、滤镜等改动画布，会记为暂停期间编辑并在面板计数。
6. 作画中点「作品信息」可修改当前作品的收集信息。进入时若正在录制，过程时钟自动暂停；「保存」更新信息并留在本页，「返回绘画」回到画布并自动恢复录制（原本手动暂停则保持暂停），未保存的修改不写入。
7. 点「结束」会写入本轮结束记录、落盘末位检查点并刷入本地存储，随后过程时钟复位为 `idle` 并回到首页。
8. 绘画进程中点「切换作品」会先提示保存当前绘画并结束本轮，确认且保存完成后回到首页，再选择目标作品（用其末位检查点替换画布）或新建作品。
9. 记录菜单里的「保存」立即把内存队列刷入本地 IndexedDB；「导出」下载 ZIP（含 `record.json` 和保留透明通道的 PNG 检查点，不铺背景色）；「本地提交」生成同一提交号的 ZIP，再次点击不会另建提交号，无远程服务时不会显示远程验收。
10. 「观看回放」或导入导出包 ZIP，只读查看记录和检查点，不改采集历史；观看回放默认 16 倍速，进度条旁可暂停/播放。

配置示例见项目根目录 `capture-config.example.json`。页面使用同内容的内置默认值。
