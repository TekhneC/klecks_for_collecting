# 当前边界

更新：2026-10-21。这里只记录仓库里已经写明、且代码没有相反实现的边界。它们还不是 Decision。

- 本仓库是 Klecks 绘画应用。过程采集是其上的本地层，基线提交为 `53e046b`。
- 格式版本为 1。原始指针和稳定后的绘制输入分开记录。过程时钟在明确暂停时停止；落笔间隙仍计入；页面隐藏不是暂停。
- 检查点 PNG 保留透明通道。排队超过 2 张时可以缺中间图，操作日志仍保留。瓦片级重放未实现。
- 本地提交只生成提交号和 ZIP。没有远程服务时，不能写成已验收。
- 重要性或事件监督、远程验收、24fps 原长视频不在当前记录里。
- 采集关闭时，指针回调不写队列、不读画布、不发请求。这个行为有文档说明；本轮没有再做笔感对比。
- 同设备长会话、真实数位板和回放大文件的响应尚未验收。自动测试不能代替这些结果。

打开已有作品或续画时是否替换画布，文档和代码冲突，见 [E0001](explorations/E0001-canvas-restore.md)，不属于本文件。
